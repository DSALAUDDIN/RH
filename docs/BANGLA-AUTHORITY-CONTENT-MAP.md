## 2. Technical Architecture & Canonical Rules
1. **Self-Canonical Rule:**
   - Every Bangla guide specifies `rel="canonical"` pointing strictly to its own `/bn/guides/[slug]` URL.
   - Example: `/bn/guides/dental-implant-cost-dhaka` -> `https://rhdentalcare.com/bn/guides/dental-implant-cost-dhaka`.
   - Never points to the English version as canonical.
2. **Hreflang Alternates:**
   - `en-BD`: `https://rhdentalcare.com/guides/[slug]`
   - `bn-BD`: `https://rhdentalcare.com/bn/guides/[slug]`
   - `x-default`: `https://rhdentalcare.com/guides/[slug]`
3. **Typography & Styling:**
   - Native font configured: `--font-bn` (Hind Siliguri via Google Fonts).
   - Applied globally via `src/app/bn/layout.tsx`.
